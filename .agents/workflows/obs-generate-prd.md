# obs-generate-prd

**Descripción**: Transforma la investigación en un Documento de Requisitos (PRD) borrador.

## Prerrequisitos
- El agente debe saber sobre qué tema o proyecto generar el PRD.

## Pasos del Agente
1. Lee `obsidian-product-doc-generator/SKILL.md`.
2. Busca notas relevantes en `03_Discovery` y `04_Meetings`.
3. Estructura la información usando `tpl_prd.md`.
4. Guarda el PRD en `02_Product/` etiquetado con `#draft`.
